## 첫번째 다시 쓰기 (2026-09-01 기준, 실제 구현 반영)

### 왜 바뀌었나

원래는 진로문장완성검사 문항으로 정서를 측정하려 했으나, **문항을 앱에 띄울 수 없게 됐다.**

- 한국가이던스 진로문장완성검사 문항 — 상용 검사 도구, 권리 미확보
- AI허브 데이터 — 학습에만 사용 가능, **문항 노출 불가** (㈜데이터드리븐 회신)

측정 도구 자체가 막혀서, 측정을 커리어넷에 넘기고 자체 문항의 역할을 바꿨다.

### 지금 하는 것

**1) 측정은 커리어넷 공인 검사가 담당한다**

- 직업가치관검사(q=6), 진로개발준비도검사(q=8) — 대학생·취준생 대상
- 판정·등급·해설은 **커리어넷 결과표**에 있다. 우리는 점수를 해석하지 않는다
- `report` API가 점수를 주지 않으므로(`{inspctSeq, url}`만) 앱 화면에 수치를 찍을 수 없다.
  결과 화면에서 검사별 상태를 보여주고 "자세히 보기"로 결과표를 연다
- 규준표가 없어 기준선을 세울 수 없다. 결과표 샘플에서 **같은 원점수 12가 영역에 따라
  백분위 1과 6으로 갈리는 것**을 확인했다. 규준을 가진 쪽만 할 수 있는 일이다

**2) 자체 문항은 측정이 아니라 정리다**

- `teen` 24문항 서술 / `jobseeker_behavior` 14문항 체크리스트 / `jobseeker_narrative` 12문항 서술
- 사용자가 한 말을 영역별·주제별로 묶어 되돌려준다 (성찰 자료. 자기소개서가 아니다)
- 타당화를 거치지 않았으므로 점수·등급을 내지 않는다

**3) LLM은 대화 진행자가 아니라 보조다**

- 응답이 얇을 때(10자 미만·회피 응답)만 되묻기 한 문장
- 결과 화면에 짧은 피드백 한 문단
- 판정 문구·자소서 대필·능력 단정은 필터로 차단
- 로컬 EXAONE-3.5-7.8B-Instruct. AI허브 국외 반출 금지 때문에 해외 API를 쓸 수 없다

### 측정하지 않는 것 — 진로불안

- 커리어넷 6영역(자기이해 / 전공 직업지식 / 진로결정확신도 / 의사결정자신감 /
  관계활용자신감 / 구직준비도)의 **영역명과 결과표 해설 어디에도 걱정·초조·압박감 같은
  정서 표현이 없다.** 결과표 샘플에서 직접 확인한 관찰이다
- 즉 공인 검사가 정서 층을 다루지 않는다. 그리고 진로개발준비도는 준비도 척도이지
  불안 척도가 아니다 — 구인이 다르다
- 자체 문항으로 불안을 점수화하는 것은 타당화 없이 불가능하다
- 지금은 `supportFlag` 문항 2개(Q7 지지체계, Q23 진로장벽)로 **신호만 포착**하고
  상담 자원을 안내한다. 점수를 매기지 않는다
- 수치를 만들려면 타당화된 진로불안 척도가 별도로 필요하고,
  **민감정보 판단이 선행**되어야 한다 (`db-plan.md` 참조)

### 아직 정하지 않은 것

- 중·고등학생 트랙에 어떤 검사를 붙일지 (24/35 중학생, 25/36 고등학생).
  학년을 어디서 받을지가 먼저다. 위 본문의 마지막 문장이 여기서 끊겨 있다
- `relm`(영역) 필드는 2020년 이후 커리어넷에서 미사용. 개선 중이나 일정 미정

### relm 복구 시 할 것 (결정됨)

**영역별 원점수를 화면에 표시한다.**

- 우리는 이미 문항별 선택값(`answerScoreNN`)을 갖고 있다. `relm`이 오면 영역별로
  합산만 하면 된다
- **백분위·T점수는 여전히 불가능하다.** 규준표는 커리어넷만 갖고 있고 API로 주지 않는다.
  판정(취약/강)은 계속 커리어넷 결과표에 맡긴다
- 원점수를 쓰면 영역 되묻기(`AreaAskback`)도 없앨 수 있다. 가장 낮은 영역을
  우리가 계산해서 후속 서술로 바로 라우팅하면 된다

**먼저 검증할 것** — 커리어넷의 실제 채점 공식(가중치·역채점)을 모른다.
`answerScoreNN` 단순 합산이 결과표의 원점수와 일치하는지 **실제 검사 1건으로 대조**해야 한다.
어긋나면 우리 계산값을 화면에 쓸 수 없다.
